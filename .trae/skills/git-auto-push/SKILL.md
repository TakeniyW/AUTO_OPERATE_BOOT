# Git Auto Push

每当你（AI agent）完成了一项编码类任务并且功能验证通过后，自动把改动 commit + push 到仓库的 main 分支。

## 触发条件

必须**同时满足**以下三个条件才执行：

1. **刚完成了编码类工作**：包括新增文件、修改现有文件、删除文件、重构、功能修复等。纯对话、纯调研、纯文档不算。
2. **功能已验证通过**：至少有一种验证方式通过（语法检查、import 测试、单元测试、端到端测试、启动验证、用户截图确认等）。如果验证失败或还没跑过，**不要 push**，先修复问题。
3. **有实质性改动**：`git status` 显示有 modified / untracked / deleted 文件，并且 `git diff --stat` 非空。没有改动则跳过。

## 执行步骤

按顺序执行，任一步失败都要报告并停止：

```bash
# 1. 切到 main 分支
git checkout main

# 2. 拉远程最新，避免落后
git pull --rebase origin main

# 3. 暂存全部改动（包括新文件）
git add -A

# 4. 确认暂存区有改动
git diff --cached --stat
# 如果输出为空 → 说明没有改动，退出 skill

# 5. 生成 commit message 并提交
# message 格式：<type>: <简短描述>
#   type 取值：feat / fix / refactor / docs / chore
#   描述：一句话说明本次做了什么，中文
#   示例：feat: gui 新增测试连接按钮与配置持久化
git commit -m "<auto-generated message>"

# 6. 推送
git push origin main
```

## Commit Message 生成规则

- **type 选择**：
  - `feat` 新功能（新增文件/模块、新 UI 面板、新参数）
  - `fix` 修复 bug（解决报错、调整逻辑、边界 case）
  - `refactor` 重构（改结构不改行为：抽函数、重命名、拆分文件）
  - `docs` 纯文档改动（README、注释、说明）
  - `chore` 杂项（依赖更新、打包脚本、配置文件）
- **描述内容**：概括本次改动的主要点，中文，尽量一句话说明白做了什么、解决了什么。
- **多文件大改动**：挑最重要的 1-2 件事写，不必罗列全部。

## 安全规则

- **绝不 push 未验证的改动**：如果功能还没跑通或不确定能否正常工作，跳过本 skill。
- **绝不 push 包含敏感数据的文件**：token、密码、密钥、私钥等文件必须在 `.gitignore` 里，或已确认不会被 `git add -A` 误暂存。commit 前可以跑 `git diff --cached | rg -i "secret|token|key|password"` 做快速检查，命中就取消提交。
- **绝不强制推送（force push）**：只允许普通的 `git push origin main`。
- **有冲突先停下**：`git pull --rebase` 或 `git push` 报冲突时，停止执行并向用户报告冲突点，不要自动解决。
- **保留用户手动提交**：如果工作区有已经 staged 但本次不相关的改动，可以用 `git reset HEAD` 先 unstage，再按需 add；或者干脆只 add 你改过的那些文件（`git add <paths>`），但用 `git add -A` 更简单，前提是工作区里没有其他乱七八糟的东西。

## 不触发的场景

- 纯调研/纯问答/纯分析的对话结束
- 修改了代码但还没验证通过
- 工作区是空的（没有 git 仓库或没有改动）
- 用户明确说"不要提交/先别 push/等我确认"
- 仓库没有配置远端 origin（`git remote -v` 为空）
- 当前不在 main 分支（用户可能在维护其他分支）—— 这种情况下先 checkout main 再继续

## 示例

```
[代码改完，语法检查通过，端到端测试跑完]
→ 触发本 skill
→ git checkout main && git pull --rebase origin main
→ git add -A && git diff --cached --stat  ← 确认有改动
→ git commit -m "feat: wallet 模块支持自动探测 MetaMask 扩展 ID"
→ git push origin main
→ 报告：已推 main，commit abc123d
```
